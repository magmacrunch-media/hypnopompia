You need Xcode, and nothing else

No Apple developer account, no signing, no clone of anything, and no cable. These run on the simulator that comes with Xcode.

  1. Install Xcode from the Mac App Store. It is free and large, about 7 GB. Open it once afterwards and let it finish installing its components.
  2. Download an app below and unzip it. You get App.app.
  3. In Xcode's menu bar, choose Xcode → Open Developer Tool → Simulator. An iPhone appears; if it does not, pick one from the Simulator's File → Open Simulator menu.
  4. Drag App.app onto the iPhone window. It installs and appears on the home screen. Tap it.
Or do it from the Terminal 
xcrun simctl install booted App.app
xcrun simctl launch booted <the bundle id listed on the app below>

If something goes wrong

  • “App.app is damaged” — macOS quarantines anything downloaded. Run xattr -dr com.apple.quarantine App.app and try again.
  • Nothing happens when you drag it on — the simulator has to be booted first, showing a home screen rather than a black rectangle.
  • “Unsupported architecture” — check the architectures listed on the app against your Mac. arm64 is an Apple Silicon Mac (M1 and later), x86_64 an Intel one. The Apple menu → About This Mac says which you have.
  • The simulator is too old — each app lists the minimum iOS it needs. Xcode → Settings → Components installs other versions.

What a simulator cannot show you

  • Game Center. These are built unsigned and without entitlements, so leaderboards and achievements do nothing. That needs a paid Apple Developer membership, which does not exist yet.
  • Haptics. There is no taptic engine in a simulator, so anything that should buzz is silent.
  • Real speed, and a real touchscreen. A trackpad pretending to be a finger on a Mac pretending to be a phone. Layout, wording and rules are worth reporting from here; how something feels is not.
